# Customer Churn Prediction System

A Machine Learning based Customer Churn Prediction System using XGBoost and Streamlit.

## Project Overview
This project predicts whether a customer is likely to leave a service (churn) using Machine Learning models.

## Features
- Customer churn probability prediction
- XGBoost classification model
- Streamlit web application
- Model evaluation
- SHAP feature importance analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SHAP
- Streamlit

## Machine Learning Models
- Random Forest
- Gradient Boosting
- XGBoost (Final Model)

## Results
Final XGBoost Model Performance:
- Accuracy: 80%
- ROC-AUC: 0.85
- F1 Score: 0.59
